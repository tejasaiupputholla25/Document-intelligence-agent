# Document Intelligence AI Agent

A production-oriented AI application for uploading documents,
asking questions about their contents, retrieving relevant
information, performing document-based analysis, and generating
grounded responses.

## Project Status

Currently under development.

## Planned Features

- Document upload
- PDF processing
- Retrieval-Augmented Generation (RAG)
- Semantic document search
- AI agent with tool calling
- Data analysis
- Streamlit chat interface
- FastAPI backend
- PostgreSQL / vector storage
- Docker
- CI/CD
- Cloud deployment
- LLM observability

## Current Phase

Phase 1: Converting the original notebook prototype into a
structured Python application.
